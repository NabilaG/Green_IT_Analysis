# 🌱 Green IT Analytics

Ce projet a pour objectif d’analyser l’impact environnemental du numérique (Green IT) et d’identifier des pistes de réduction des consommations d’énergie et des émissions liées aux infrastructures informatiques.

## 🎯 Question business

Comment une organisation peut-elle réduire l’empreinte carbone de son IT (datacenters, serveurs, postes de travail, usage du cloud, etc.) tout en conservant un niveau de service efficace et fiable ?

## 🎯 Objectifs du projet

- Quantifier la consommation énergétique et/ou les émissions liées à l’IT.
- Identifier les principaux postes “énergivores” (datacenters, applications, stockage, réseau…).
- Simuler des scénarios de réduction (optimisation serveurs, virtualisation, cloud plus vert, bonnes pratiques utilisateurs…).
- Présenter les résultats dans un dashboard clair orienté décision.

## 🧠 Approche analytique

1. **Collecte des données** : recherche et sélection de jeux de données liés au Green IT (consommation énergétique, émissions, scénarios d’optimisation).
2. **Nettoyage & préparation** : vérification de la qualité des données, formats, valeurs manquantes, cohérence des unités.
3. **Analyse & structuration** : création d’indicateurs clés (kWh, CO₂, coûts estimés, gains potentiels).
4. **Visualisation & storytelling** : création d’un dashboard BI et d’un résumé exécutif pour expliquer les résultats et les recommandations.

## 📊 Outils prévus

- Power BI (dashboard principal)
- Excel / SQL pour la préparation des données
- GitHub pour la gestion du projet et la documentation
